# EXT_mesh_manifold fixtures

`TwoMaterialBox.glb` was generated by `manifold-3d@3.4.1` through Tau's
Manifold kernel. It is the union of two adjacent 10 mm cubes with red and blue
material runs and calculated vertex normals.

The single glTF mesh contains:

- 40 POSITION and NORMAL values;
- two indexed TRIANGLES render primitives of 30 indices each;
- one `EXT_mesh_manifold` canonical primitive of 60 indices;
- 38 sparse index replacements exposed as `mergeIndices` and
  `mergeValues`; and
- one closed, oriented solid with 20 triangles.

The source program is:

```ts
import { Manifold, setMaterial } from 'manifold-3d/manifoldCAD';

const left = setMaterial(
  Manifold.cube([10, 10, 10]).translate([-10, 0, 0]).calculateNormals(0),
  { baseColorFactor: [0.8, 0.1, 0.1], attributes: ['NORMAL'] },
);
const right = setMaterial(
  Manifold.cube([10, 10, 10]).calculateNormals(0),
  { baseColorFactor: [0.1, 0.2, 0.8], attributes: ['NORMAL'] },
);
export default left.add(right);
```

The `invalid/` directory contains deterministic mutations of that file and
small indexed tetrahedra. Together they exercise the extension's accessor,
merge, primitive, half-edge, vertex-link, and triangle validation rules. The
test case names state the single invariant changed in each file; the simple
tetrahedra use the same POSITION accessor for the render and canonical
primitives so they do not depend on sparse-accessor behavior.
