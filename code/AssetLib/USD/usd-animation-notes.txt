# GLTF IMPORTER ANALYSIS 🔍

## glTF Source Data (SimpleMorph.gltf)
- **Animation**: 1 animation with 1 sampler targeting node 0 "weights"
- **Time samples**: 5 keyframes from 0.0 to 4.0 seconds (accessor 4)
- **Weight values**: 10 float values = 5 time samples × 2 morph targets (accessor 5)
- **Mesh weights**: Default weights [0.5, 0.5] on mesh

## glTF2 Importer Processing (CreateMeshMorphAnim)
- **Time conversion**: `times[i] * 1000.0f` (line 1448) - converts seconds to milliseconds
- **Final times**: [0, 1000, 2000, 3000, 4000] milliseconds 
- **Animation duration**: Set to last keyframe time (4000ms = 4.0 seconds)
- **TicksPerSecond**: Hardcoded to 1000.0 (line 1616)
- **Weight stride**: `output->count / numKeys` = 10/5 = 2 weights per keyframe
- **Values array**: `mValues[j] = j` (sequential indices: 0, 1)
- **Weights array**: `mWeights[j] = values[k]` (actual animation values)

## Expected Animation Data Structure
```
aiAnimation {
  mDuration = 4000.0 (4 seconds in milliseconds)
  mTicksPerSecond = 1000.0
  mNumMorphMeshChannels = 1
  mMorphMeshChannels[0] {
    mName = "nodes[0]" 
    mNumKeys = 5
    mKeys[0] { mTime=0,    mWeights=[?, ?] }
    mKeys[1] { mTime=1000, mWeights=[?, ?] }
    mKeys[2] { mTime=2000, mWeights=[?, ?] }
    mKeys[3] { mTime=3000, mWeights=[?, ?] }
    mKeys[4] { mTime=4000, mWeights=[?, ?] }
  }
}
```

## ROOT CAUSE IDENTIFIED 🎯

### USD Exporter Sampling Bug
**Location**: USDZExporter.cpp animation sampling loop
**Issue**: Only sampling first keyframe (animTime=0 only matches mTime=0)
**Root Cause**: Sampling logic `animTime >= key.mTime && (keyIdx == morphAnim->mNumKeys - 1 || animTime < morphAnim->mKeys[keyIdx + 1].mTime)` only finds first keyframe for most frames
**Impact**: All USD time samples get [0,0] weights instead of animated values

### Fix Required
- ✅ glTF importer: Working correctly
- ❌ USD sampling: Need to properly interpolate between keyframes
- ❌ Time conversion: Need to handle 24fps sampling vs 1fps keyframes
